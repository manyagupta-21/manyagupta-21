## 📌 Selected Work

### 📉 Yield Curve Forecasting
- Analysed 30+ years of US Treasury yields alongside macroeconomic indicators
- Tested stationarity and temporal dependence using ADF/KPSS and ACF/PACF
- Compared ARIMAX, VAR, and Dynamic Nelson-Siegel models
- Improved forecast accuracy by up to 32% RMSE over Random Walk; integrated into a pricing system

### 📊 Monetary Policy and Market Volatility
- Analysed the impact of RBI monetary-policy communication on NIFTY 50 and India VIX
- Represented policy content using TF-IDF and GloVe to capture inflation, growth, and liquidity themes
- Combined policy signals with lagged returns and momentum using Random Forest, RNN, and LSTM models

### 🏦 Mortgage Credit Risk Analytics
- Built a PD, LGD, EAD, and Expected Loss framework using 33M+ Freddie Mac records
- Selected XGBoost based on Brier score (0.12) and PR-AUC (0.74)
- Built LGD with a 2-stage GLM; stress-tested Expected Loss across crisis vintages

### 📄 FilingIQ
- Built a RAG pipeline over annual filings of JPMorgan, Bank of America, and Goldman Sachs
- Processed 10,870 text segments with all-MiniLM-L6-v2 embeddings, indexed in FAISS
- Designed a RetrievalQA chain (Groq-hosted LLM via LangChain) with a Streamlit UI for source attribution

### 🛡️ longevityRiskR (R Package)
- Developed an R package for stochastic mortality modelling to quantify longevity risk
- Modelled mortality using exponential improvement and Gaussian shocks; Monte Carlo pricing
- Built a ruin-probability framework to assess insolvency risk and survival probabilities

### 🤖 ControlPlane.ai: AI Risk-Control Layer
- Building a real-time Python control layer scoring LLM responses for performance, cost, and risk
- Designing Brier, self-consistency, PSI, and KS monitoring to detect hallucination and drift
- Implementing a tiered allow/edit/review/block policy under asymmetric FP/FN costs

### 👥 Customer Segmentation
- Segmented 2,000+ customers using demographic and behavioural data
- Reduced 29 features to 2-3 principal components via PCA
- Compared K-Means, Hierarchical, and Gaussian Mixture clustering (0.71 silhouette score)

### ⚡ Energy Consumption Prediction
- Built an end-to-end pipeline with preprocessing, encoding, and feature selection
- Validated OLS assumptions (VIF, Breusch-Pagan, Durbin-Watson, Jarque-Bera)
- Compared OLS, Ridge, Lasso, and Elastic Net; achieved 80.8% test R² with Elastic Net

### 🚗 Vehicle Damage Severity Analysis
- Built a multi-label deep learning model to classify 6 vehicle damage types (CarDD dataset)
- Designed a computer vision pipeline with COCO annotation parsing and image augmentation
- Benchmarked CNN, VGG16, and ResNet50; best Macro F1-score of 72.2% with VGG16
